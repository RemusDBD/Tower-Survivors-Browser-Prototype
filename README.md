# Tower Survivors Browser Prototype

This is a lightweight browser-playable HTML/CSS/JavaScript prototype inspired by
the reference data from `https://github.com/RemusDBD/TowerSurvivorsv1.91`.

## What It Includes

- stationary center tower
- auto-firing stackable weapons
- timed shop with weapon and upgrade cards
- gold income and kill bounty
- status effects: burn, poison, frost, freeze
- defensive upgrades: armor, mana shield, spikes, regeneration
- escalating enemy pressure and a 6-minute survival win condition

## Controls

- `P`: pause or resume
- `R`: restart run
- mouse: click a shop card to purchase it

## Files

- `index.html`: game structure and HUD
- `styles.css`: layout and visual styling
- `game.js`: combat loop, enemy AI, shop logic, and rendering
